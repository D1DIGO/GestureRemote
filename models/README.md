The official Google MediaPipe Gesture Recognizer task bundle belongs here.
Run `python scripts/download_model.py` from the project root. This downloads
the fixed **float16/version 1** bundle over HTTPS; inference uses the CPU.
The model is excluded from Git. No training or custom dataset is required.

Source: https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/1/gesture_recognizer.task

Model documentation and license information:
https://ai.google.dev/edge/mediapipe/solutions/vision/gesture_recognizer#models
